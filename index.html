三、參加培訓前後，我的能力有什麼不同？

請先想想「參加今天培訓之前的自己」，再評估「參加今天培訓之後的自己」。每一列都要選兩個分數。

分數說明：1＝還不太會；2＝不太會；3＝普通；4＝大致會；5＝很會。請依照自己的真實感受填答，沒有標準答案。

四、今天的學習收穫

1. 今天的培訓，哪一部分對你最有幫助？
2. 今天有沒有哪一件事，是你原本不會、現在比較會了？
3. 培訓結束後，你願不願意在學校或展覽現場，試著向其他人介紹一幅畫？
4. 今天的培訓讓你對藝術、博物館或導覽產生更多興趣嗎？

問卷使用與分析說明

建議施測方式

  1. 於培訓結束前10分鐘，由老師或工作人員引導學生填答。
  2. 每位學生獨立填寫，不記錄姓名；基本場次欄位可由帶隊老師統一說明。
  3. 請學生依「培訓前」與「培訓後」兩個時間點回想並評分。
  4. 建議每場次保留參與人數、實際出席人數及有效問卷數，以計算問卷回收率。

成效指標建議

主要指標為八項能力的前後測平均差、後測達4分以上比例，以及願意嘗試導覽和學習興趣的比例。可依縣市、梯次、年級及首次參訓與否比較。

目前問卷的前後測屬學生回溯式自評，適合做單場活動的初步成效評估；若要確認學生是否真的能在眾人面前導覽一幅畫，建議另由老師使用簡短觀察表，評估學生是否能完成開場、作品觀察、內容說明及回應提問。

SROI 對應與限制

  • 成果數量：有效填答人數、各項能力後測達4分以上人數、前後測有提升人數。
  • 成果程度：前後測平均分差及學生自評的改變程度。
  • 歸因線索：「今天的培訓對我的幫助有多大」可作為學生主觀感受的輔助資訊，但不能直接當成精確歸因百分比。
  • 成果持續性：本問卷是單次培訓的即時自評，無法直接證明能力會維持多久；如需了解長期改變，建議另做後續追蹤。
  • 財務代理變數：不建議直接將問卷分數乘上課程市價。應先確認成果定義、受益人數、成果期間及財務代理變數的合理性，再計算並調整 deadweight、attribution、drop-off 等因素。

與現有 SROI 的銜接

現有 Impact Map 的小尖兵培訓成果包含藝術認知、自主學習、學習熱情、口語表達、思考、創意、臨場應變、領導、人際互動及團隊合作。本問卷將其轉化為學生能理解的題目；正式分析時，建議保留與既有 SROI 指標的對照表，避免把單次培訓成果直接擴大解讀為整年度小尖兵服務成果。
